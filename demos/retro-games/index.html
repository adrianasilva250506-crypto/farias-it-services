    How a retro site works

    This demo runs small games written for the web. A full retro games site adds an emulator, and here's how that fits together.

    01

    An emulator in the browser

    Tools like EmulatorJS run classic consoles inside the web page, using WebAssembly. Nothing to install.

    02

    Only legal games

    The library is built from homebrew games whose makers allow it, public domain titles, or games the player owns.

    03

    Saves and controllers

    Save states keep your progress, and the browser's Gamepad API connects USB and Bluetooth controllers.

    04

    Accounts and leaderboards

    A small database stores players, favourite games and a shared high-score table.

    Good to know: putting commercial games (ROMs) online without permission is piracy, even if they're very old. A professional retro site works with homebrew developers or licensed collections instead.

    Questions

    Do I need to install anything?

    No. Everything runs in your web browser, on a computer, tablet or phone.

    Can I play with a controller?

    Yes. Plug in or pair a gamepad, press any button, and use the stick or d-pad. The A button starts the game, Start pauses it.

    Does it work on my phone?

    Yes. Use the on-screen buttons, or drag your finger on the screen to move the paddle in Brick Blaster and Paddle Duel.

    Are my high scores saved?

    In this demo, they're kept in your browser only. Clearing your browser data removes them.

    Can you add famous console games?

    Only with the right licences. This demo uses original games so there's no copyright problem.
